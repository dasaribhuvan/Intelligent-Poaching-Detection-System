# WildGuard AI Detection System

Welcome to the WildGuard AI Detection System!

## Important Note: Model File
Due to GitHub's file size limits, the large machine learning model file (`best.pt`) is **not included in this repository**.

You must download the model file manually before running the backend server.

**Download link:** [best.pt from Google Drive](https://drive.google.com/file/d/10scV0k90Z6-D4twSdvhgn0ccNElzOLm6/view?usp=sharing)

### Where to place the model file
Once downloaded, please place the `best.pt` file inside the `backend/models/` folder:

```
Intelligent-Poaching-Detection-and-Response-System.../
└── backend/
    ├── app/
    └── models/
        └── best.pt  <-- Place the downloaded file here
```

If the `models/` folder does not exist inside the `backend/` directory, create it first.
